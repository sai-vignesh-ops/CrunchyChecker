Project setup — Windows

1 Create your project folder
mkdir CrunchyChecker
cd CrunchyChecker
2 Put these 3 files in the folder
📄 baron_checker.py — your original scraper
📄 bridge.py — the WebSocket bridge (downloaded above)
📄 cr_gui.html — this file
3 Install dependencies (run once)
pip install requests websockets PySocks
4 Start the bridge every time you use it
python bridge.py
You'll see: CrunchyChecker Bridge — ws://localhost:8765
5 Open cr_gui.html in Chrome/Edge
Double-click cr_gui.html. The bridge dot in the top-right will turn green when connected. Paste your combos and hit Start.
Proxy format reminder
ip:port:user:pass
user:pass:ip:port
ip:port
socks5://user:pass@ip:port
⚠ Results are saved automatically to output/cr_hits_XXXXXX.txt and output/cr_free_XXXXXX.txt in the same folder.
